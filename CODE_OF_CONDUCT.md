# Code of Conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, give constructive feedback, and keep discussions focused on the work. Harassment of any kind is not tolerated.

Report unacceptable behaviour by opening a private [security advisory](https://github.com/GonzaloAlarconRoldan/GUI-PlaywrightMCP-Framework/security/advisories/new) or contacting the maintainer through their GitHub profile.
